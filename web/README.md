# Web App XML Local

Esta carpeta contiene la aplicación web para ejecutar ejercicios XML de forma local.

## Archivos

- `index.html` - Interfaz de usuario
- `app.js` - Lógica de validación, XPath y XQuery en el navegador
- `style.css` - Estilos visuales

## Uso

1. Abre `web/index.html` en un navegador.
2. Selecciona las secciones de la barra lateral.
3. En el paso de XPath/XQuery, usa las consultas predefinidas o escríbelas manualmente.

## Características

- Validación de XML con esquema XSD.
- Ejecución local de XPath y simulación de XQuery.
- No requiere servidor ni BaseX.

## Recomendación

Si quieres una experiencia más cómoda, instala la extensión "Live Server" en VS Code y abre `web/index.html` con ella.
